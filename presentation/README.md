# Pitch deck

`VitaNatura365-pitch.pptx`: 10 slides, about 8 minutes including a 4-minute live demo.
Speaker notes with timings are on every slide (View > Notes in PowerPoint).

Flow: title, problem, for every tourist, solution, Marta's story, **live demo**, real data,
why it matters for Dubrovnik, business and next steps, closing. The QR codes open the live app.

To change the text or design, edit `build-deck.js` and rebuild:

```bash
cd presentation
npm install
node build-deck.js
```

Photos come from `web/public/img`, icons from Phosphor (same as the app).
